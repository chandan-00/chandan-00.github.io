NFL Scouting-Report Agents

Six Claude agents in LangGraph write fact-checked NFL opponent scouting reports.

Highlights
  • Orchestrates 6 Claude Haiku agents in LangGraph over 26 deterministic DuckDB stat tools: a planner, offense, defense, and injury analysts, and an editor.
  • A fact-checker re-runs every cited tool call and sends failed claims back for revision, reaching 100% final claim accuracy across 120 reports (single-agent baseline: 99.5%).
  • Evaluation harness plants wrong values, teams, and splits in drafts and catches 99.9–100% of them, with at most one false positive per configuration.
  • Re-derived about 2,840 claims independently in Polars (100% tool agreement) and scored 360 reports against a frozen, hashed snapshot of games after the model's training cutoff.
  • 3-way ablation over 40 games with 3 repeats, tracked in MLflow: the multi-agent design ranked first in 7 of 10 blind-graded games and scored +0.72 on a 1–5 scale (paired bootstrap 95% CI +0.33 to +1.10).
  • Weekly live reports for all 32 teams at $0.03–0.05 per report using prompt caching and strict tool schemas.
  • Stack: Python, LangGraph, Claude API, DuckDB, Polars, MLflow, Streamlit
Financial Complaint Classifier

Sorts consumer-finance complaints into six product categories, served on serverless AWS.

Highlights
  • Sorts complaint narratives into credit reporting, debt collection, mortgage, credit card, checking/savings, and student loans with fine-tuned DistilBERT.
  • Built a balanced 8,100-example dataset with leakage controls (exact-duplicate and conflicting-label narratives removed before splitting); a TF-IDF + logistic regression baseline led DistilBERT on macro-F1 (0.893 vs 0.874).
  • Asynchronous AWS pipeline: an API Lambda behind API Gateway queues requests on SQS, and a containerized inference Lambda writes predictions to DynamoDB, with a dead-letter queue and least-privilege IAM.
  • All 28 resources provisioned in Terraform; validated end to end in a local AWS emulator and with pytest + moto contract tests before any cloud spend.
  • INT8 ONNX quantization cut model size 75% (268 → 67 MB) and sped CPU inference 1.56× without observed macro-F1 degradation.
  • At 3008 MB, inference reached 170 ms warm p95 and cut median duration 31% versus 2048 MB at roughly equal estimated cost.
  • Stack: Python, PyTorch, Hugging Face, ONNX Runtime, Docker, Terraform, AWS (Lambda, SQS, API Gateway, DynamoDB, ECR, S3, CloudWatch)
